设置

登录 autodl.com 后，在开发者工具 → Application → Local Storage 复制 token。

登录 gpushare.com 后，开发者工具 → Application → Cookies → https://www.gpushare.com → 复制 gpu_share_token。

登录 matpool.com 后，开发者工具 → Network → 任意请求 → Request Headers 的 authorization，复制 Bearer 后面的 JWT。

同一个请求头里的 x-matpool-user-id，例如 123456。

控制台 → 账户中心 → API 密钥：console.compshare.cn/uaccount/api_manage。用于读取实时在售状态与价格。
