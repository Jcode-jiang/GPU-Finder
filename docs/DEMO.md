# 演示录制脚本

发布前建议用低预算账户录制一段 30–60 秒视频，展示：

1. 打开菜单栏面板，切换显卡型号；
2. 打开 Dashboard，切换预设并查看平台实时状态；
3. 点「租」，展示实时报价、价格上限和确认框；
4. 创建后展示 SSH 命令（密码默认隐藏）；
5. 点释放，展示确认框与最终状态（不要展示真实密码/完整 IP）。

录制要求：

- 使用测试账户，实例选择最低价、最短可用时长；
- 录制前清空余额/手机号/Token 等敏感信息，或用 `<redacted>` 覆盖；
- 不把录制文件提交到仓库，上传到 Release 附件或文档链接；
- 当前仓库只提供截图，尚未附 GIF/视频，避免伪造操作过程。
