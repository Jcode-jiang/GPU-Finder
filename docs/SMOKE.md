## 后续 UI 解码修复

- 矩池云 quote 的 `image_id` 原为整数，Swift `RentQuote.imageId` 是字符串，导致“格式不正确”；已统一为字符串。
- 恒源云创建返回的 `auto_stop_at` 是 ISO 字符串，Swift 按整数解码失败。创建实际已成功，实例已手动释放；后端已统一转成 Unix 时间戳。
- 项目所有者复测优云智算成功；本文件保留自动化脚本的失败记录，便于区分环境/密码差异。


## 矩池云修复

- 自动镜像从“任意 PyTorch 应用镜像”改为优先 `Pytorch x.y.z` 基础镜像，避免 Wan/ComfyUI 等应用镜像长时间初始化；
- 17区第三方资源需要平台卷支持，当前在报价阶段明确提示不支持，不再发送会失败的创建请求；
- A100 16区基础镜像已实测 Running + SSH + released。
